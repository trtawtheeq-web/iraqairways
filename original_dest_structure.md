# Original Destination Page Structure (Sochi example)

## Layout:
1. **Header**: Blue top bar with nav links (Book, Manage, My trips, Add-ons, Plan trip, Deals, Need Help?) + KWD/EN + Login
2. **Hero Section**: 
   - Large title: "Cheap Flights to Sochi (AER)" - centered, dark navy
   - Subtitle: "Adventure, elegance, and a splash of seaside breeze" - centered, gray
   - Breadcrumb: Home / Book Flights / Flights To Sochi
   - Large hero image (full width, rounded corners)
3. **Description paragraph**: Centered text about the destination
4. **"Things to do in [City]"** section:
   - Title: "Things to do in Sochi"
   - Subtitle: "Top attractions"
   - Grid of attraction cards (image + title + description)
5. **More sections below** (scrollable)

## Key Design Elements:
- Background: Light blue/white gradient
- Title font: Large serif-like, dark navy
- Breadcrumb: Small text with links
- Hero image: Full width with rounded corners
- Attraction cards: Image on top, title, description below
- Clean, minimal spacing

## Attractions Section:
- Card carousel with prev/next arrows (dark blue circles)
- Each card: Large image (tilted/stacked effect), title below in dark navy, description paragraph
- Example: "The Sochi Arboretum" with description
- Cards appear stacked with a 3D perspective effect

## More Experiences Section (below attractions):
- Another section with more content
- "Moremall" - shopping description

## Key Visual Elements:
- Attraction images have a "stacked cards" 3D perspective effect
- Dark blue circular prev/next navigation buttons
- Title is centered below the image
- Description text is centered, gray color

## "More experiences" Section:
- Horizontal carousel with description text on left, large image on right
- Prev/Next arrows (gray/dark blue circles)
- Shows parks, attractions with descriptions

## "Retail gems" Section:
- Title: "Retail gems" in light gray
- Prev/Next arrows on the right
- Grid of 3 cards (images of shopping malls/areas)
- Each card: Image + title + description

## Overall Page Sections (top to bottom):
1. Hero (title + subtitle + breadcrumb + hero image)
2. Description paragraph
3. "Things to do in [City]" - stacked card carousel
4. "More experiences" - horizontal carousel (text left, image right)
5. "Retail gems" - grid of 3 cards
6. More sections (restaurants, hotels, etc.)
7. Flight search CTA
8. Footer
