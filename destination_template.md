# Destination Page Template (from Sochi example)

## Page Structure:
1. Header: Jazeera nav bar (same as homepage)
2. Title section: "Cheap Flights to [City] ([IATA])"
3. Subtitle: Short tagline about the city
4. Search widget bar: From (Kuwait, KWI) — To ([City], [IATA]) — Date range — Passengers — Arrow button
5. Breadcrumb: Home / Book Flights / Flights To [City]
6. Hero image: Large rounded image of the city
7. Description paragraph about the city
8. "Things to do in [City]" section title + "Top attractions" subtitle
9. Attractions carousel: Cards with tilted images, title, description, prev/next arrows
10. "Retail gems" section: Shopping/restaurant cards with arrows
11. Footer

## Sections observed:
- Hero image (full width, rounded)
- Welcome text paragraph
- "Things to do" with carousel of attractions (image cards that tilt/rotate)
- Each attraction: image + title + description
- "Retail gems" section with shopping/dining cards
- "Moremall" card example: title + description text

## Design elements:
- Background: #F0F8FF (light blue)
- Title: Large serif-like font, dark navy
- Search widget: rounded pills with icons
- Attraction cards: tilted/rotated images with shadow
- Navigation arrows: circular dark blue buttons with < >
